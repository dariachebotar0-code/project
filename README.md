## 📖 О проекте

Данный проект был разработан в рамках дипломной работы. Система предназначена для комплексной автоматизации розничного предприятия: от управления товарами и складскими запасами до работы с клиентами и программой лояльности. Приложение имеет две роли — **Администратор** и **Клиент**, каждая со своим набором функций и интерфейсом.

---

## 🎯 Основные функции

### Для администратора
- 🔐 Безопасная авторизация с хешированием паролей (SHA-256)
- 📊 Главный экран с карточками статистики и графиком выручки за неделю
- 📦 Складской учёт: добавление, изменение цены, списание, поступление товаров
- 👥 Управление персоналом, поставщиками и филиалами
- 🎁 Программа лояльности: просмотр клиентов, начисление баллов
- 💬 Обработка сообщений от клиентов
- ✏️ Редактирование справочного контента без изменения кода
- 🖨️ Формирование и печать отчётов (ценники, накладные, купоны)

### Для клиента
- 🛍️ Каталог товаров с поиском, фильтрацией и увеличенными фото
- 🔒 Бронирование товаров (не более 5 шт., на 3 дня)
- ❤️ Избранное с подсчётом общей стоимости
- 🎫 Купоны: генерация за баллы, использование, печать
- 🛒 Терминал самообслуживания для проверки цены по штрих-коду
- 🔔 Система уведомлений о бронированиях
- 📧 Обратная связь с администратором
- 📖 Интерактивная справка и схема этажей универмага

## 📊 Структура базы данных

База данных состоит из **19 таблиц**, включая:

- `Products` — товары и их характеристики
- `Customers` — клиенты и карты лояльности
- `Employees` — сотрудники
- `Suppliers` — поставщики
- `Orders` — бронирования
- `Sales` / `SaleDetails` — продажи и состав чеков
- `SupplyInvoices` / `SupplyDetails` — поставки
- `Coupons` — купоны на скидку
- `Notifications` — уведомления клиентов
- `Messages` — обратная связь
- `HelpContent` — редактируемый справочный контент
- `KioskHistory` — история проверок в терминале

Все таблицы связаны внешними ключами, обеспечивающими целостность данных.

## 🚀 Установка и запуск

1. Склонируйте репозиторий:
```bash 
git clone https://github.com/dariachebotar0-code/project.git
2. Откройте файл RadugaERP.sln в Visual Studio 2022
3. Убедитесь, что установлен .NET Framework 4.7.2 и SQL Server LocalDB
4. Запустите приложение через Visual Studio (F5)
5. Используйте учётные данные для входа:
Администратор: логин admin, пароль admin123
Клиент: номер карты лояльности (например, RDG-0518-3472), пароль 12345
