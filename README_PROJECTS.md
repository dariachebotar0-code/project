# 📁 README — 4 веб-проекта (дизайн-эксперименты)

Этот репозиторий содержит **4 полноценных веб-сайта**, разработанных в рамках дизайн-экспериментов. Каждый проект — это самостоятельная страница с уникальной темой, стилем и интерактивностью. Все проекты выполнены на чистом HTML + CSS + JavaScript без использования внешних библиотек.

## 1. 🏛️ AG Studio — Архитектурное бюро (AG studio.html)

**Описание:**  
Сайт архитектурного бюро и студии ландшафтного дизайна в минималистичном стиле с тёплой, благородной цветовой гаммой. «Эфирная» эстетика — лёгкость, воздушность, чистая типографика и природные оттенки.

**Особенности:**
- 🏗️ Асимметричный герой-блок с крупной типографикой и изображением
- 🖼️ Галерея проектов с фильтрацией по категориям (Сады, Террасы, Водоёмы)
- 👥 Команда специалистов с ролями, фотографиями и стажем
- 📝 Блог с актуальными статьями о ландшафтном дизайне
- 📞 Контактная форма с валидацией и картой
- 🎯 Услуги с ценами и кнопкой «Заказать» (автозаполнение формы)
- 🌙 Переключение светлой/тёмной темы
- 🌐 Поддержка двух языков (RU/EN) через систему data-i18n
- 🔐 Авторизация и регистрация (localStorage)
- 📊 Личный кабинет с историей заявок
- 🖼️ Модальные окна для просмотра проектов с возможностью заказа

**Технологии:** HTML, CSS (кастомные свойства, адаптив, Grid/Flexbox), JavaScript (SPA-навигация, Intersection Observer, модальные окна, i18n)

## 2. ✈️ ethereal — Авиапутешествия  (`ethereal.html`)

**Описание:**  
Сайт авиакомпании или сервиса по поиску авиабилетов с лёгкой, воздушной эстетикой. Выполнен в светлых, тёплых тонах с мягкими облачными фонами и плавными анимациями. Создаёт ощущение лёгкости и вдохновения к путешествиям.

**Особенности:**
- ☁️ Анимированные облака на фоне (CSS-анимация с плавающим эффектом)
- ✈️ Герой-блок с летящим самолётиком и вдохновляющим текстом
- 🔍 Умная форма поиска авиабилетов с заполненными значениями (откуда, куда, дата)
- 🏙️ Карточки направлений (Лиссабон, Киото, Кейптаун, Мехико) с ценами, рейтингом и информацией о перелёте
- ⏱️ Ближайшие рейсы с обратным отсчётом до вылета (динамический JavaScript-таймер)
- ⭐ Отзывы пассажиров с рейтингом
- 🎯 Преимущества авиакомпании (ручная кладь, питание, медиатека, экологичность)
- 📧 Форма подписки на новости
- 🎨 Glass-morphism эффекты (прозрачные карточки с размытием)
- 📱 Полная адаптивность под все устройства

**Технологии:** HTML, CSS (анимации, glass-morphism, backdrop-filter, Grid/Flexbox), JavaScript (таймер обратного отсчёта, обработка форм, интерактивные элементы)

## 3. 🎵 NEON WAVE — Студия звукозаписи (`NEON WAVE.html`)

**Описание:**  
Сайт музыкальной студии в тёмной неоновой эстетике. Яркие акценты — розовый и голубой неон на угольно-чёрном фоне. Создаёт атмосферу ночного клуба и современной музыкальной индустрии.

**Особенности:**
- 🎵 Анимированная звуковая волна на главном экране (CSS-анимация)
- 🎤 Карточки услуг с ценами и иконками (запись вокала, инструментов, сведение, создание битов)
- 🎧 Плейлист с треками (интерактивные карточки с имитацией воспроизведения по клику)
- 📊 Статистика студии (150+ треков, 30+ артистов, 5 лет работы)
- 📞 Контактная информация с иконками (адрес, телефон, email, соцсети)
- 📝 Форма заявки с валидацией
- 🎯 Кнопки-переходы между страницами
- 🌐 Поддержка двух языков (встроена в структуру)

**Технологии:** HTML, CSS (анимации, градиенты, неон-эффекты, keyframes, Grid/Flexbox), JavaScript (SPA-навигация, обработка кликов)

## 4. 🖥️ CodeForge — Школа программирования (CodeForge.html)

**Описание:**  
Сайт онлайн-школы программирования с акцентом на практическое обучение. Выполнен в свежей, современной цветовой гамме с бирюзовыми акцентами. Полноценная SPA с переключением страниц, тем и языков.

**Особенности:**
🎓 Каталог курсов с ценами, длительностью, форматом обучения и записью на курс
👨‍🏫 Карточки преподавателей с опытом и специализацией
⭐ Отзывы студентов с каруселью на главной
📝 Блог со статьями о программировании
📞 Контактная форма с валидацией и формой записи на пробное занятие
🔐 Авторизация и регистрация (localStorage)
📊 Личный кабинет с отображением записанных курсов
🌙 Переключение светлой/тёмной темы
🌐 Поддержка двух языков (RU/EN) через data-i18n
🎯 Интерактивная запись на курсы с проверкой авторизации
📈 Статистика на главной (количество курсов, студентов, трудоустройство)

Технологии: HTML, CSS (кастомные свойства, адаптив, анимации), JavaScript (SPA-навигация, i18n, Intersection Observer, слайдер)

## 🛠️ Общие технологии

| Компонент | Технология |
|-----------|------------|
| Язык разметки | HTML5 |
| Стилизация | CSS3 (Flexbox, Grid, кастомные свойства, анимации, keyframes) |
| Программирование | Vanilla JavaScript (ES6) |
| Хранение данных | localStorage (настройки, пользователи, заявки, записанные курсы) |
| Адаптивность | Медиа-запросы (mobile-first, от 320px до 1440px) |
| Интернационализация | Собственная i18n-система (переключение RU/EN через data-i18n) |
| Шрифты | Google Fonts (Inter, Space Mono, IBM Plex Sans) |
| Изображения | Pexels (CDN) с fallback-обработкой ошибок |
| Анимации | CSS @keyframes, Intersection Observer для появления при скролле |
| Навигация  | SPA-архитектура с переключением страниц без перезагрузки |

## 📱 Адаптивность
Все проекты корректно отображаются на:
💻 Десктопах (1200px+)
📟 Ноутбуках (1024–1200px)
📱 Планшетах (768–1024px)
📱 Телефонах (320–768px)
🌐 Поддержка языков
В проектах CodeForge (1.html) и AG Studio (3.html) реализована поддержка русского и английского языков через систему data-i18n:
Навигация
Заголовки и описания
Подписи кнопок и полей
Контактная информация
Карточки услуг и проектов
Сообщения системы (тосты)
Проекты ethereal (2.html) и NEON WAVE (4.html) выполнены на русском языке с возможностью лёгкого расширения.

🔐 Авторизация
В проектах CodeForge (1.html) и AG Studio (3.html) реализована система авторизации:
📝 Регистрация (имя, email, пароль) с валидацией
🔑 Вход в личный кабинет
📊 Личный кабинет с историей заявок и записанными курсами
🚪 Выход из аккаунта
Данные хранятся в localStorage.
